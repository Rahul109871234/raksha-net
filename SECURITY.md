## Reporting a Vulnerability

As RAKSHA-NET is a research reference prototype for sovereign 5G/NTN cyber-resilience, security audits and vulnerability reports are highly welcome.

If you discover a security vulnerability (such as a cryptographic weakness, side-channel attack vector, or routing state-machine bypass):
1. **Do not open a public GitHub issue.**
2. Send an email to the project maintainers:
   - G. Rahul Reddy: `24bec038@iiitdmj.ac.in`
   - Dr. Satish Kumar Tiwari: `stiwari@iiitdmj.ac.in`
3. Include:
   - A description of the vulnerability.
   - Proof-of-concept code or step-by-step reproduction instructions.
   - Potential impact on confidential telemetry or routing stability.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
